Bot executable
Built locally with Cargo in release mode for x86_64-unknown-linux-musl. It is an ELF static PIE and has no dynamic shared-library dependencies for the Rust application. The default terminal log level is `warn`; set `RUST_LOG=info` to show details or `RUST_LOG=error` for errors only. This build also includes adaptive in-memory media encryption, a safe disk fallback, temporary-file cleanup after upload attempts, and exclusion of the initial /yt URL metadata-and-quality-list phase from CPU EMA sampling. The sampler resets its baseline after that phase.
